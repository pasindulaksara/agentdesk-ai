
# AgentDesk AI 🤖

An AI agent and automation platform built with Python, FastAPI, and Ollama.

## 🎯 Project Goal

Build a practical AI agent capable of understanding tasks, selecting tools, executing actions, and automating workflows.

## 🛠 Tech Stack

- Python 3.11
- FastAPI
- Pydantic
- Ollama (planned)
- AI Tool Calling (planned)

## ✅ Current Features

- FastAPI backend
- Health check endpoint
- Task submission endpoint
- Swagger API documentation

## 🚧 Upcoming Features

- Ollama LLM integration
- AI agent with tool calling
- Agent execution loop
- Workflow automation
- Agent memory
- Error handling and evaluation

## 🚀 Getting Started

Install dependencies:

```bash
pip install -r requirements.txt
```

Start the API:

```bash
uvicorn app.main:app --reload
```

API documentation:

http://127.0.0.1:8000/docs
